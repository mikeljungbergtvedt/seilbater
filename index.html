Én engangs-oppsett

For at siden skal kunne legge til båter automatisk trenger den et GitHub personal access token som lagres kun i din nettleser (localStorage). Det sendes aldri noe annet sted enn til GitHub selv, direkte fra din maskin.

Bruk samme seilbater-push-token som ble opprettet ved oppsettet. Hvis du mistet det: lag et nytt her — Contents: Read and write på repoet seilbater.

Tokenet lagres kun lokalt i denne nettleseren. For å nullstille — åpne konsollen og kjør localStorage.removeItem('gh_pat').
